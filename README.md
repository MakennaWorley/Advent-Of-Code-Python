# Advent of Code Solutions

This repository contains my solutions to the annual **Advent of Code** programming challenges.
Advent of Code is a yearly set of algorithmic programming puzzles designed to build problem-solving
skills across a wide range of difficulty levels.

The solutions here emphasize **correctness first**, followed by choosing appropriate algorithms
based on problem constraints rather than forcing a single approach.

---

## Repository Structure

Each year is organized into its own directory, with:
- individual solution files per day
- a year-specific README that breaks down the algorithms used and why they were chosen

## Notes
- Solutions are written for clarity and correctness rather than extreme micro-optimizations.
- Many problems were solved iteratively: starting with a straightforward approach, then refining
  the algorithm once constraints and patterns became clear.
- Year-specific READMEs provide detailed explanations of algorithm categories and design choices.

## 2024

Solved all 25 Advent of Code problems using **Python**, applying a mix of:
- brute force
- heuristic search
- graph algorithms
- dynamic programming
- simulation
- greedy algorithms

Solutions were chosen based on problem constraints and algorithmic complexity rather than a single
fixed approach. For some of the more challenging problems, I referenced community discussions and
other solution write-ups to better understand advanced techniques and alternative strategies.
